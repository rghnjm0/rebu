# Rebu

**Rebu** — минималистичная социальная платформа на Flask, вдохновлённая Reddit и Pikabu. Позволяет создавать тематические сообщества, публиковать посты с медиа, обсуждать и голосовать.

---

## Возможности

### Пользователи
- Регистрация и вход по логину/паролю
- Безопасное хеширование паролей (Werkzeug)
- Обратная совместимость со старыми SHA-256 хешами
- Редактирование профиля: аватар, цвет, биография
- Система банов пользователей

### Сообщества
- Создание сообществ с латинским именем (3–20 символов)
- Подписка/отписка от сообществ
- Лента «Мои сообщества»
- Управление модераторами сообщества

### Посты
- Создание постов: текст + загрузка изображений (PNG, JPG, GIF, WEBP, до 16 МБ)
- Поддержка встроенной загрузки изображений через редактор
- Два режима главной ленты: **Новое** и **Горячее** (алгоритм на основе рейтинга и возраста)
- Пагинация (20 постов на страницу)
- Редактирование и удаление своих постов
- Закладки (сохранение постов)
- Закреплённые посты в сообществах

### Голосование и комментарии
- Upvote / Downvote постов
- Комментарии к постам
- Удаление своих комментариев

### Поиск
- Поиск постов по тексту
- Поиск сообществ

### Модерация
- Роли: `user`, `moderator`, `admin`
- Удаление постов и комментариев модераторами
- Система жалоб на посты и комментарии
- Панель обработки жалоб для модераторов
- Бан/разбан пользователей (только admin)
- Назначение ролей (только admin)
- Логи действий администратора

## Стек технологий

| Компонент | Технология |
|---|---|
| Бэкенд | Python 3.8+, Flask 2.3+ |
| База данных | SQLite (через встроенный модуль `sqlite3`) |
| Безопасность | Werkzeug (`generate_password_hash`, `check_password_hash`) |
| Шаблоны | Jinja2 (HTML-шаблоны) |
| Стили | Кастомный CSS, Font Awesome |

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_НИК/rebu.git
cd rebu
```

### 2. Создание виртуального окружения

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте файл-пример и заполните значения:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
SECRET_KEY=ваш-секретный-ключ-замените-это
FLASK_DEBUG=false
```

> ⚠️ Никогда не используйте `FLASK_DEBUG=true` в продакшене.

### 5. Инициализация базы данных

```bash
python init_db.py
```

### 6. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: **http://127.0.0.1:5000**

## Основные маршруты

| Маршрут | Описание |
|---|---|
| `/` | Главная лента (новые) |
| `/hot` | Главная лента (горячие) |
| `/r/<name>` | Страница сообщества |
| `/post/<id>` | Страница поста |
| `/create` | Создать пост |
| `/create_community` | Создать сообщество |
| `/communities` | Все сообщества |
| `/u/<username>` | Профиль пользователя |
| `/bookmarks` | Закладки |
| `/search` | Поиск постов |
| `/moderation/reports` | Панель жалоб (модератор) |
| `/admin` | Административная панель |
